## Module contract
src/game.js exports createGame(saved?), serialize(game), tick(game, dtSeconds), move(game,dx,dy,dtSeconds), act(game, tileX?,tileY?), sleep(game), buySeeds(game), sellHarvest(game), interact(game).
State: {player:{x,y,facing}, day, time (minutes since midnight), energy,maxEnergy, coins,seeds,harvest, selected (hoe|seeds|water|harvest), tiles (array of {x,y,tilled,watered,crop:null|{growth}}), message, stats:{harvested,sold}, questComplete, ...}.
World coordinates tiles: width 40 height 28. Player starts at x=19.5 y=16.5. Farm plots rectangle x=14..23,y=12..18. Cottage rectangle x=6..11,y=5..10; shop x=28..33,y=5..10; pond x=28..35,y=18..23. Solid collision buildings, pond (except the visible pier), outer boundary. Door interactions: cottage (9,11) sleep; shop (30,11) buy seeds; shipping box (12,11) sell. E interact nearby; tools space or click within ~2 tiles; keyboard 1..4 selects tools.
Goal: harvest/sell 12 turnips, build 300g total earnings. Start with 12 seeds, 80g. Watered crop grows overnight, ready after 3 watered days. Day starts 6am, time passes; sleep restores energy. Saves browser localStorage via parent. No server player data.
src/render.js exports async createRenderer(canvas) returning {render(game,dtSeconds),screenToWorld(clientX,clientY),resize(),destroy?}. Rendering sizes canvas against CSS clientWidth/clientHeight, DPR; provides a lush detailed farm with pixel art sprites, buildings, pond, vegetation, crops, character, decorations and animated water. Camera may be fitted or follow player. screenToWorld returns {x,y}. Renderer must tolerate initial state.
Parent UI: attractive title/start overlay, HUD, tool belt, contextual nearby interactions, journal/help, keyboard/touch controls, autosave and sound toggle. Renderer draws game only. Share contract changes early.
