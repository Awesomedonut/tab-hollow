# Native farm chickens and signs

Ridgeside Village artwork by Rafseazz and the upstream graphics contributors, from pinned revision `1f3bf6d73039d4b7bec7c9d70a0a1e7ea971f6b9`. Non-SMAPI artwork is licensed **CC BY-SA 4.0** by the preserved upstream README. Full source URLs, input SHA256, exact source crops, output SHA256, frame padding and anchors are in `public/assets/ridgeside-farm-props/provenance.json`; README, contributor credits and complete license accompany the crops.

The supplied VM candidates were inspected as actual native pixels and source hashes verified against `/home/codex/research/clover-native-props/{RVanimals.png,zridgesideCraftables.png}`. Every opaque output pixel is preserved from those source rectangles. Four chicken cells are padded to 20×16 with foot anchor [10,15]; animation uses all four cells and per-frame mirroring as travel changes direction. The native 16×32 wooden sign keeps anchor [8,31], placed at the prior post's ground contact. Project-authored FARM/POND text sits on the board, with the already-cleared RePixel young-crop adaptation or original wave pixels as a location marker. No source scaling, recoloring or synthetic body pixels are introduced.

The upstream WhiteChicken companion configuration refers to `Animals/White Chicken` in the base game. That referenced vanilla asset is **not** the included map-sheet candidate and is neither accessed nor shipped. The reviewed README and credits carry no conflicting notice for the selected source sheets/crops; the selected CC BY-SA artwork keeps its attribution and share-alike terms. This review does not clear unrelated Ridgeside art or every third-party/vanilla asset mentioned by that repository.

VM integration captures are in `/home/codex/research/clover-overnight/character/20260916T061625Z/final/`. The actual renderer keeps native pixels and existing wandering routes, contact shadows and depth ordering. Chickens remain decorative, not an animal-care gameplay feature. The native signs are narrower/taller than the old placeholder boards. Source crops and the resulting whole scene require continued strict visual review; this is not a fidelity claim.
