# Ridgeside Village character artwork

The playable farmer uses Ian's actual directional walking sprites from **Ridgeside Village**, by Rafseazz and the Ridgeside Village contributors. The native frames are 16 × 32 pixels; all four directional rows and their four authored stride frames are retained.

Source: https://github.com/Rafseazz/Ridgeside-Village-Mod/tree/1f3bf6d73039d4b7bec7c9d70a0a1e7ea971f6b9
