# Ridgeside Village native props

Fence, barrel and timber-decking pixels are cropped from the official Ridgeside Village Stardew Valley mod by **Rafseazz and the Ridgeside Village contributors**.

Source: https://github.com/Rafseazz/Ridgeside-Village-Mod/tree/1f3bf6d73039d4b7bec7c9d70a0a1e7ea971f6b9

The official project's README licenses non-SMAPI subdirectories under **Creative Commons Attribution–ShareAlike 4.0 International**: https://creativecommons.org/licenses/by-sa/4.0/. These extracted art files and their adaptations remain under that license. The root MIT license covers code, not these art assets.

The compact atlas preserves original pixel dimensions and colors. Exact source filename, SHA-256, source crop coordinates and destination coordinates are recorded in public/assets/ridgeside-props/provenance.json. Horizontal fence cells use the original strip endpoints; middle cells are repeated to fit the farm fence lengths. Native porch flooring supplies pier boards.
