# Simple Foliage scenery

The maple, pine, mahogany, cherry, and ordinary static bush/tuft sprites in
public/assets/simple-foliage/ are authored pixel art from **Simple Foliage**
by **Azrashar / itsanette**, uploaded under **dugongkebalik**.

- Author's original mod and permissions: https://www.nexusmods.com/stardewvalley/mods/8164
- Author's official forum release: https://forums.stardewvalley.net/resources/simple-foliage.66/
- Accessible download mirror: https://github.com/JettyQuin/Valley-Girls-1.6-Modpack/tree/main/mods/%5BCP%5D%20Simple%20Foliage
- Mirror package manifest credits the original artist and unofficial update authors Sevinae and tophatta. Only ordinary original foliage is used here.
- Exact mirror commit, source paths, crop coordinates, native dimensions, drawing anchors, and checksums are recorded in public/assets/simple-foliage/provenance.json.

## Stated permissions

The original author's page states:

> Upload permission: You can upload this file to other sites but you must credit me as the creator of the file.

> Modification permission: You are allowed to modify my files and release bug fixes or improve on the features so long as you credit me as the original creator.

> Conversion permission: You can convert this file to work with other games as long as you credit me as the creator of the file.

> Asset use permission: You are allowed to use the assets in this file without permission as long as you credit me.

The author also writes:

> Feel free to use all my assets and recolor/edit them however you want but if you intend to publish it somewhere/upload it on the internet, please contact me! I'd love to see how my assets are being used :3

This last note is preserved as a request to hear about uses. No contact has been sent on the user's behalf.

These assets retain their author's stated terms; they are not claimed as CC0,
MIT-licensed project artwork, or original Clover Hollow artwork.

## Included and excluded art

Included sprites are native-resolution transparent crops; colors and pixel
details are unchanged. Maple is tree2_spring, pine is tree3_spring, and
mahogany is tree8_spring. The ordinary bushes are the pre-1.6 static map
patches at (208, 0, 48, 48), (208, 48, 32, 32), and (240, 48, 16, 32). The flowering cherry is the original static map sprite at (256, 0, 96, 112).

The oak tree credited to acerbicon, third-party recolor variants, vanilla game
tiles, green-rain trees and bushes, mystic trees, and new flowers are excluded.
The [unofficial update's author notes](https://www.nexusmods.com/stardewvalley/mods/20972)
expressly distinguish publicly usable original itsanette artwork from its
new green-rain trees, bushes, and mystic tree. This project uses only the
original ordinary foliage regions above.
